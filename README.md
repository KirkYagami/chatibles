# Chatbots!
I'll dedicate this repo to have as many chatbots as possible, from the very simple, cli based, to complex agents helping in so many ways.

---

## Purpose:
To have a central repo to understand the basics of creating chat applications with LLMs.

---

## Setup
- clone the repo
- setup the venv with all the requirements
- provide API keys - refer the .env.sample and create a .env file with actual values

---
## Examples:


```sh
❯ python .\cli\01-studybot.py
============================================================
  Study & Tech Stack Learning Assistant
  Type 'exit' or 'quit' to end the session.
============================================================

You: I want to learn Machine learning.

Assistant: That's great to hear! Machine learning is a fascinating field with a lot of opportunities. To get started, it's important to have a structured learning path. Here’s a roadmap to help you begin your journey in machine learning:

1. **Strengthen Your Foundation in Mathematics:**
   - **Linear Algebra:** Understand vectors, matrices, and operations on them.
   - **Calculus:** Focus on derivatives, integrals, and gradients.
   - **Probability and Statistics:** Learn about distributions, expected values, variance, and statistical tests.

2. **Programming Skills:**
   - **Python:** It's the most popular language in the machine learning community. Make sure you're comfortable with Python syntax, libraries, and frameworks.
   - Familiarize yourself with libraries like NumPy, pandas, and Matplotlib for data manipulation and visualization.

3. **Data Understanding and Preprocessing:**
   - Learn to clean and preprocess data. Understanding how to deal with missing data, outliers, and categorical variables is crucial.
   - Explore tools like Jupyter Notebooks for interactive data analysis.

4. **Introduction to Machine Learning:**
   - Start with supervised learning (e.g., linear regression, logistic regression) and unsupervised learning (e.g., clustering, dimensionality reduction).
   - Understand the basic concepts such as overfitting, underfitting, and cross-validation.

5. **Explore Key Algorithms and Techniques:**
   - Decision Trees, Random Forest, and Gradient Boosting.
   - Support Vector Machines (SVM).
   - Neural Networks and Deep Learning (using frameworks like TensorFlow or PyTorch).

6. **Hands-on Practice:**
   - Work on projects and datasets from platforms like Kaggle or UCI Machine Learning Repository.
   - Implement algorithms from scratch to deepen your understanding.

7. **Advanced Topics:**
   - Dive deeper into deep learning, reinforcement learning, and natural language processing (NLP).
   - Study current trends and state-of-the-art models.

8. **Develop a Portfolio:**
   - Showcase your skills with projects, blogs, or even a GitHub repository.
   - Participate in hackathons or contribute to open-source projects.

9. **Stay Updated and Connect:**
   - Follow machine learning communities, forums, and conferences.
   - Engage with online courses, MOOCs, and certifications from platforms like Coursera, edX, or Udacity.    

Do you have any specific areas within machine learning you’re more interested in, like computer vision, NLP, or maybe reinforcement learning? Or maybe you have questions about resources or learning platforms? Let me know how I can assist further!

You: exit

Assistant: Goodbye! Best of luck on your learning journey!
```
